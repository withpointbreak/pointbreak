Review stages and the CLI

Work -> Claims -> Evidence -> Questions -> Call maps to capture of one exact Revision in a stable Change, then observation, validation, input-request, and assessment. change attention lists outstanding judgment; association records where that exact Revision landed—the same revision already under review.

Review is local, read-only, and advisory. Validation is evidence, never a verdict or merge gate.
